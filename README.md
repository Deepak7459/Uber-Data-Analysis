## 🚗 Uber Ride Data Analysis Project

### 📌 Project Overview

This project focuses on analyzing Uber ride data to extract meaningful insights that help understand customer behavior, ride patterns, cancellations, payment modes, and overall operational performance. The analysis is performed using **Excel, SQL, and Power BI**, with proper documentation and visualization.

The goal of this project is to apply **data analytics concepts** to real-world transportation data and present insights through an interactive dashboard and structured reports.

---

### 🛠 Tools & Technologies Used

* **Excel** – Data cleaning, preprocessing, and initial analysis
* **SQL (PostgreSQL/MySQL)** – Data querying and analysis
* **Power BI** – Interactive dashboards and data visualization
* **MS Word** – Project documentation & synopsis
* **MS PowerPoint** – Project presentation

---

### 📂 Dataset Description

The dataset includes Uber ride booking information such as:

* Booking ID
* Trip Status (Completed, Cancelled, etc.)
* Pickup & Drop Location
* Distance Travelled
* Payment Mode
* Customer & Driver Ratings
* Date and Time Details

*(Dataset source: Kaggle)*
